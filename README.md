# YellowText

YellowText does what its name suggests, it makes button hover text yellow. Nothing less and nothing more, it does not even require Fabric API.

This is a 26.1+ port of the [original mod](https://github.com/MisterCheezeCake/YellowText), which you can also find on [Modrinth](https://modrinth.com/mod/yellowtext).
